# 📚 Library Management System

A simple **Python-based console application** for managing books in a library. This project allows users to search for books, view all available books, issue books, view issued books, add new books, and delete books through a menu-driven interface.

## 🚀 Features

* 🔍 Search for a book using Book ID
* 📚 Display all books
* 📤 Issue a book
* 📋 Display issued books
* ➕ Add a new book
* 🗑️ Delete a book
* 🚪 Exit the application
* 🗂️ Store book information using Python dictionaries

## 🛠️ Technologies Used

* **Python**
* Python Dictionaries
* Functions
* Conditional Statements
* Loops
* User Input
* Basic CRUD Operations

## 📌 How It Works

The application provides a menu where the user can select different library operations. Book details such as book name, release date, number of pages, parts, and availability status are stored in a Python dictionary.

The program continues running until the user selects the **Exit** option.

## ▶️ How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or any terminal.
4. Run the Python file:

```bash
python library_management.py
```

5. Select an option from the menu and follow the instructions.

## 🎯 Learning Purpose

This project was created to practice **Python fundamentals**, including dictionaries, functions, loops, conditional statements, user input, and basic data management.
